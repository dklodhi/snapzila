### Key decisions locked (reinforced by code analysis)
- **Phase 1 scope**: 6 opportunity types, 15 institution categories (submit-only), helpline, 2 tools, full console, user features, EN+HI.
- **Out of scope**: HireZila, private jobs, Nexus, crawler, API monetization, Telegram/WhatsApp bots, MOOC, campus drives, forums, push notifications, email, AI, languages beyond EN+HI.
- **Brand color**: Indigo `#4F46E5` + Sunset Orange `#F97316`. Old brand color retired.
- **Stack**: Next.js 16 + TypeScript (strict, zero `any`) + Tailwind 4 + shadcn/ui + **Supabase (native, NO Prisma)** + **Supabase Auth (NOT custom JWT)** + next-intl + PostHog.
- **URL strategy**: root = English India (no prefix), `/hi-in/` for Hindi — matches the old project's good URL pattern, simplified to 2 locales.
- **DB schema**: 20 tables, JSONB for flexible fields, RLS on every table from day 1.
- **Post view**: timeline/twitter-style with parent post partial + AJAX "View All" + sticky live-updates rail on desktop.
- **Code quality bar**: strict TS, zero `any`, no `console.error/warn` in committed code (use PostHog wrapper), no `TODO/FIXME` on `main`.
