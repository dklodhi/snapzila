# S04 — Institutions

**Date**: 2026-11-16
**Session goal**: Public submit-only institutions + console moderation queue + category listing pages.

## What happened

### DB Migration (20261116000004)
- `institutions` table (25 cols) — 16 category enum, search_vector trigger, soft delete
- `institution_submissions` table (18 cols) — public submit queue with status flow
- 3 enums: institution_category (16 values), institution_status (4), submission_status (4)
- Cross-table FKs: institutions↔submissions bidirectional; event_discussions.institution_id → institutions.id (deferred from S3)
- ~12 RLS policies: public read published, team CRUD, auth submit, submitter read own
- Public read policy for discussions on published institutions

### Public Pages
- `/institutions` — 16 category cards
- `/institutions/[category]` — published institutions grid (sorted by name, up to 100)
- `/institutions/submit` — submit form (requires login), split into server page + client SubmitForm component

### Console Pages
- `/console/institutions` — moderation queue (submissions table with status tabs) + published institutions list
- `/console/institutions/[id]` — dual-purpose:
  - Submission ID → review page with publish form (editable fields) + reject form (with reason)
  - Institution ID → edit form (all fields)

### Server Actions
- `submitInstitution` — public submit (auth required)
- `publishSubmission` — creates institution + marks submission approved + audit log
- `rejectSubmission` — marks rejected with reason + audit log
- `saveInstitution` — updates existing + audit log
- `deleteInstitution` — soft delete + audit log

## DB changes
- 2 tables, 3 enums, 1 trigger, ~12 RLS policies, 3 FKs
- Total: 14 tables
