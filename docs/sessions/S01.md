# S01 — Auth & RBAC

**Date**: 2026-11-16
**Session goal**: Consumer signup/login, team login, role-based access, RLS tested.

## What happened

This session combined the S0 foundation (Next.js app setup) with S1 (Auth & RBAC) since auth requires the app to exist first.

### Foundation (S0 portion)
- Next.js 16 + TypeScript (strict) + Tailwind 4 + shadcn/ui set up in the existing repo.
- Design tokens from `DESIGN_SYSTEM.md` applied as CSS variables.
- Fonts: Plus Jakarta Sans (display) + Inter (body) via `next/font`.
- Base UI components: button (with asChild/Slot), input, label, card.
- `lib/utils/cn.ts` + `lib/utils/log.ts` (no `console.error` in committed code).

### Auth & RBAC (S1 portion)
- **Supabase clients**: browser (`createBrowserClient`), server (`createServerClient` + next/headers), middleware helper (`updateSession`).
- **DB migration** `20261116000001_team_members.sql` applied to Supabase:
  - `team_members` table (8 cols, UUID PK, FK to auth.users)
  - Enums: `team_role`, `team_member_status`
  - Helper functions: `is_team_member()`, `has_min_role()` (role hierarchy)
  - 6 RLS policies (self read, team read all, super_admin insert/delete/update, self update)
- **super_admin user** created via Auth Admin API: `admin@snapzila.com` → team_members row (role=super_admin, status=active).
- **Auth pages**: `/login`, `/signup`, `/logout`, `/console/login` (separate dark-themed team login with team_members check).
- **Protected pages**: `/me` (consumer dashboard via `requireUser()`), `/console` (team dashboard via `requireTeamMember()`).
- **Route guards**: `src/proxy.ts` (Next.js 16 renamed from middleware.ts) refreshes session + protects `/console/*` and `/me`.
- **Server helpers**: `getCurrentUser`, `getTeamMember`, `requireUser`, `requireTeamMember`, `requireRole`.
- **Client hooks**: `useCurrentUser`, `useTeamMember` (subscribe to auth state).
- **RLS test**: 4/4 pass — admin can read, consumer blocked from read + insert.

## Issues hit + fixed
1. Next.js 16: `middleware.ts` → `proxy.ts`, export `middleware` → `proxy`.
2. TS strict: `@supabase/ssr` `setAll(cookiesToSet)` implicit any → explicit `CookieEntry[]` type.
3. `useSearchParams` needs `<Suspense>` wrapper for static generation.
4. Supabase direct host IPv6-only → used IPv4 pooler (`aws-0-ap-south-1.pooler.supabase.com`).
5. Auth Admin API needs service_role in both `apikey` + `Authorization` headers.
6. Removed hardcoded admin password from test file → reads `SNAPZILA_ADMIN_PASSWORD` env var.
