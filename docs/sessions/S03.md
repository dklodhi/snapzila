## What happened

### DB Migration (20261116000003)
- `event_discussions`: voice-type comments (event_id, institution_id, author_id, voice_type, body_md, parent_id, upvote_count, reply_count, deleted_at)
- `discussion_votes`: upvotes (unique per user per comment)
- `voice_type` enum: aspirant, selected, mentor, official, skeptic, general
- Vote count trigger + reply count trigger
- RLS: public read on published events, auth insert, author/team delete

### Public Site
- **Shell**: SiteHeader (logo, nav, auth-aware buttons) + SiteFooter (3-column links) + PublicShell wrapper
- **Home** (`/`): hero + type buttons + latest 9 events + auth status banner
- **Opportunities landing** (`/opportunities`): 6 type cards with counts + latest 12 events
- **Type listing** (`/opportunities/[type]`): up to 50 events, EventCard grid
- **EventCard**: type badge (colored), featured pill, title, conducting body, summary, days-left
- **Single event** (`/opportunities/[type]/[slug]`):
  - Desktop: 2-col (parent+guide+dates | sticky timeline rail)
  - Mobile: single column (parent → timeline → guide → dates → discussions)
  - ParentPostPartial: partial view + "View All" AJAX expand (URL hash #details)
  - EventTimeline: realtime subscription (postgres_changes INSERT), kind-colored dots, "new" pulse, relative time
  - EventGuide: accordion of sections
  - EventDates: list with optional links
  - DiscussionSection: sort toggle (Top/Recent), pseudonymous avatars (UUID hash), colored voice badges, upvote (optimistic UI), one-level replies, post form, reply form, "Login to join" prompt
