# S02 — Console Core

**Date**: 2026-11-16
**Session goal**: Console can create, edit, publish all 6 opportunity types — via Manual editor AND JSON paste editor with samples. Plus static pages, settings, audit log.

## What happened

### DB Migration (20261116000002)
- 9 new tables: `tags`, `events` (41 cols), `event_updates`, `event_guides`, `event_dates`, `event_documents`, `static_pages`, `site_settings`, `audit_logs`.
- 7 enums for content types, statuses, kinds, sections.
- `search_vector` tsvector on events (trigger-maintained).
- `create_event_from_json(payload)` RPC for the JSON paste editor.
- RLS on every table (~30 policies).

### Console Shell
- **Left sidebar**: dark theme, grouped nav (Main / Content / System), active-link highlighting, placeholders for S4/S5/S7.
- **Top bar**: New Post dropdown (Manual / JSON), user menu (avatar, email, role, logout, view public site).
- **Route groups**: `(auth)/login` (no shell) + `(shell)/` (with shell + `requireTeamMember()`).

### Post Management
- **List** (`/console/posts`): filterable by type, status. Table view.
- **Manual Editor**: 
  - New: `/console/posts/new-manual` — core fields form.
  - Edit: `/console/posts/[id]/edit` — core fields + 3 inline child editors:
    - Live Updates (add/delete, 7 kinds)
    - Guide Sections (add/delete, 7 sections)
    - Important Dates (add/delete)
- **JSON Paste Editor** (`/console/posts/new-json`): textarea + Load Sample + Validate (Zod) + Create (RPC). 6 realistic samples in `public/json-samples/`.

### Static Pages + Settings + Audit Log
- `/console/pages` — list + new + edit (slug, title EN+HI, body markdown EN+HI, SEO, header/footer placement).
- `/console/settings` — KV editor for brand_name, taglines, default_locale, footer_columns.
- `/console/audit-log` — viewer with action filter, actor email + role.

### Server Actions
All mutations centralized in `src/lib/console/actions.ts`. Every action writes an audit log entry.

## DB changes
- 10 tables total (team_members + 9 new).
- ~30 RLS policies.
- 5 functions (is_team_member, has_min_role, set_updated_at, events_update_search_vector, create_event_from_json).

## Build status
`npm run build` passes. 16 routes:
- Public: `/`, `/login`, `/signup`, `/logout`, `/me`
- Console: `/console`, `/console/login`, `/console/posts`, `/console/posts/new-manual`, `/console/posts/new-json`, `/console/posts/[id]/edit`, `/console/pages`, `/console/pages/new`, `/console/pages/[id]/edit`, `/console/settings`, `/console/audit-log`

## Issues fixed
1. Route group relative imports — moved actions to `src/lib/console/`.
2. TS strict `email[0]` undefined — added `?? "?"` fallback.
3. Zod v4 `z.record()` needs 2 args — added `z.string()` key schema.
4. Server action bind order — swapped delete function signatures to match bind order (eventId first, childId second).
5. `saveSiteSetting` form action — changed to accept FormData.
